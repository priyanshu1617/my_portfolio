# Priyanshu Chandra | Personal Portfolio

Welcome to my personal portfolio repository! This is a modern, responsive, and dynamic web portfolio built to showcase my skills, projects, and journey as an aspiring Software Engineer and MERN Stack Developer.

## 🚀 Live Demo
[https://priyanshu1617.github.io/my_portfolio/](https://priyanshu1617.github.io/my_portfolio/)

## ✨ Features
- **Modern UI/UX**: Designed with a sleek, glassmorphism aesthetic and dynamic background particles.
- **Responsive Design**: Fully responsive across all devices (mobile, tablet, desktop).
- **Dynamic Projects Section**: Fetches and displays projects directly from GitHub.
- **GitHub Stats Integration**: Displays real-time GitHub streak and contribution heatmap.
- **Interactive Elements**: Typing effects, smooth scrolling, and hover animations.
- **Contact Form**: Functional UI for a contact form.

## 🛠️ Tech Stack
This portfolio is built entirely using vanilla web technologies, keeping it lightweight and fast:
- **HTML5**: For semantic structuring.
- **CSS3**: For styling, animations, flexbox/grid layouts, and responsive design.
- **JavaScript (Vanilla)**: For interactivity, fetching GitHub data, dynamic typing effects, and particle background.

## 📂 Sections Include
1. **Hero Section**: Welcome message with dynamic typing effect, quick links, and a glowing avatar.
2. **About Me**: Details about my educational background, journey, and focus areas (MERN, Django, Java DSA).
3. **Skills**: Categorized view of my technical skills (Frontend, Backend, Languages, Tools).
4. **Projects**: Dynamic grid displaying my GitHub repositories using GitHub's API.
5. **Stats**: Real-time GitHub contribution statistics.
6. **Contact**: Get in touch via a sleek contact form or social links.

## 💻 Local Development

To run this project locally, simply clone the repository and open the `index.html` file in your browser, or use a local development server like Live Server in VS Code.

```bash
# Clone the repository
git clone https://github.com/priyanshu1617/my_portfolio.git

# Navigate to the project directory
cd my_portfolio

# Open index.html in your preferred browser
```
